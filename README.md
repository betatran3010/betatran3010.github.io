# Tran Le's portfolio

React + Vite + TypeScript + Tailwind.

```bash
npm install
npm run dev        # http://localhost:3000/portfolio/
npm run build
npm run deploy     # builds and publishes dist/ to the gh-pages branch
```

- Projects live in `data/projects.tsx`. A project with `externalUrl` links out; the rest open a case study at `#project/<id>`.
- Add `humanLine` and `aiLine` to a project to turn on the "Show AI layer" switch on the home page.
- Colors and fonts are tokens in `tailwind.config.js` and `index.css`.
- The home banner is `public/images/hero-scene.webp`, generated by `tools/generate_hero_scene.py` (needs Python, numpy, Pillow). Swap in your own illustration any time.
